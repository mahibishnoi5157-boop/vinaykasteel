# Vinayaka Steel & Railing — Website

Professional business website for **Vinayaka Steel & Railing**, a steel and railing fabrication company in Bengaluru, Karnataka, India.

## Structure

- **`frontend/`** — React (Vite) UI: pages, components, styling
- **`backend/`** — Node.js (Express) API for contact form

## Tech Stack

- **Frontend:** React 18, React Router, Vite, CSS (navy/silver theme)
- **Backend:** Node.js, Express, CORS

## Setup & Run

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs at [http://localhost:3000](http://localhost:3000).

### Backend

```bash
cd backend
npm install
npm start
```

Runs at [http://localhost:5000](http://localhost:5000). Contact form submissions are logged to the console (replace with DB or email in production).

### Production Build

```bash
cd frontend
npm run build
```

Output is in `frontend/dist`. Serve with any static host; point API requests to your backend URL.
